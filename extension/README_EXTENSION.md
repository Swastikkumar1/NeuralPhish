# NeuralPhish - Chrome & Edge Extension Guide

Protect your **WhatsApp Web**, **Gmail**, **Outlook Web**, and web browsing with real-time AI phishing detection.

---

## 🚀 How to Install in Google Chrome / Brave / Opera

1. Open your browser and navigate to:
   ```
   chrome://extensions
   ```
2. In the top-right corner, turn **ON** the switch for **Developer mode**.
3. In the top-left corner, click **"Load unpacked"**.
4. Browse and select this folder:
   ```
   C:\Personal files\NeuralPhish\NeuralPhish\extension
   ```
5. Click **Select Folder**. The **NeuralPhish Messenger Shield** extension is now installed!
6. Click the Extensions (puzzle piece) icon in Chrome and click the **Pin** icon next to NeuralPhish.

---

## 🌐 How to Install in Microsoft Edge

1. Open Edge and navigate to:
   ```
   edge://extensions
   ```
2. In the left sidebar, turn **ON** **Developer mode**.
3. Click the **"Load unpacked"** button at the top.
4. Select the folder:
   ```
   C:\Personal files\NeuralPhish\NeuralPhish\extension
   ```
5. Done!

---

## 🛡️ How to Use It

### Method 1: Right-Click Context Menu in WhatsApp Web & Gmail
- **Check any link:** Right-click on any link inside WhatsApp Web, an email, or website -> click **"🛡️ Scan Link with NeuralPhish"**.
- **Check entire message:** Highlight any message text in WhatsApp or Gmail -> right-click -> click **"🛡️ Scan Message with NeuralPhish"**.
- NeuralPhish will immediately show a browser notification with the verdict (DANGEROUS, SUSPICIOUS, or SAFE).

### Method 2: Extension Popup
- Click the NeuralPhish shield icon in your browser toolbar.
- Paste any WhatsApp message or link to analyze it instantly.
- Click **"Scan Current Tab"** to inspect the security of the website you are currently browsing.

> **Note:** The local NeuralPhish server must be running on your PC (`http://127.0.0.1:5000`) for the extension to analyze threats. Launch it by double-clicking `run.bat`!
